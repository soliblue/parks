# Parks design system

Concepts:

- `design/parks-desktop-concept.png`
- `design/parks-mobile-concept.png`

The desktop surface is a 380px information rail beside a full-height rounded map. Mobile is a full-bleed map above a rounded bottom sheet.

## Tokens

- Background: true white `#ffffff`
- Foreground: `#0a0a0a`
- Surface: `#f7f7f7`
- Elevated: `#ededed`
- Accent: `#34c759`
- Display: Fraunces 600
- Prose: Lora 400
- UI: system sans
- Type: 24 / 22 / 16 / 14 / 12px
- Space: 4 / 8 / 12 / 16 / 24px
- Radius: 8 / 14 / 20px
- Borders: foreground at 15% opacity
- Shadows: floating map, sheet, and controls only
