# Parkblick

Berlin-first public parks explorer at `https://parks.soli.blue`.

- Keep the public app static-first.
- Fetch and normalize official data at build time.
- Use no paid Google services.
- Use shared design tokens before one-off values.
- Keep views presentational and geo/data logic in hooks or libraries.
- Preserve visible source, license, freshness, and methodology notes.
- Every user-visible change must pass desktop and mobile browser QA.
