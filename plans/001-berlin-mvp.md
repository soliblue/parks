# Berlin MVP

## Goal

Ship a Berlin-first public parks explorer at `parks.soli.blue`, using official open data and no paid Google services.

## Status

- [x] Reference and data research
- [x] Desktop and mobile concepts
- [x] Static data pipeline
- [x] Map and information rail
- [x] Search, filters, geolocation, and distance bands
- [x] Browser and visual QA
- [x] Git, Cloudflare Pages, and custom domain

## Contracts

- Canonical park ID is the official PITID.
- Runtime remains static.
- Distance bands are explicitly estimates, not routed isochrones.
- Berlin WFS data and basemap attribution remain visible.
- Missing amenity coverage is never presented as a negative fact.
